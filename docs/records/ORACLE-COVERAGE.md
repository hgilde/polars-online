## 1. Purpose and definitions

This record lists every user-facing model, feature and parameter. For each
it says whether an oracle or a known dataset holds the numbers, and names
the test. It exists so the gaps can be closed in order of risk.

| term | meaning here |
|---|---|
| oracle | an independent computation of the same quantity |
| [T] | a third-party library computes the quantity itself: scikit-learn, scipy, statsmodels, numpy, pandas, polars, river, filterpy, hmmlearn, padasip, Vowpal Wabbit, `bayesian_changepoint_detection`, LightGBM, XGBoost |
| [L] | a longhand: the paper's or the docstring's definition written out with independent arithmetic (`tests/reference.py`, `tests/reference_paths.py`, a definition inside the test). A Rust test whose definition is written by hand and solved by faer's LU or eigensolver (`crates/online-core/src/oracle.rs`) is [L] too: faer does the algebra, not the statistics |
| [P] | a published value: a paper's table or worked example, or certified values |
| not an oracle | chunk invariance, save and load, kept-vs-fresh, bit identity with another configuration of this library, property and equivariance tests, and `tests/reference_cluster.py`, which transcribes the Rust |
| known dataset | a public dataset with a published result the test reproduces or bounds |
| known truth | seeded synthetic data with a planted generating truth; weaker, marked separately |
| COVERED | an oracle or a known dataset holds the feature at the forms a user reaches, including its default |
| PARTIAL | held only at some values, forms or models (the row says which), or only by reduction to another configuration of this library |
| GAP | no oracle and no known dataset; only behaviour, limits or self-comparison |
| N/A | changes no number a user reads (a thread count, a memory bound, a refusal, a cadence), so its correct test is bit identity with the unsplit run, which the suite has |

A longhand counts as an oracle, as the brief's definition allows. But it
was written in this project, so it can share a misreading of the paper. §3b
lists the rows held by a longhand alone, as a second list for the next
pass.

Test paths are relative to `tests/` unless they start with `crates/`. A
Rust test is named by its file and function. The oracle ledger
(`oracles.toml`, 67 groups and 777 cases at task 320) holds the heavy grids. A row says
"ledger `group`" where one of its groups records the case.

## 4. Candidate sources (researched)

Read from each candidate's source or reference docs on 2026-11-01, and
held against this library's definition in its module docs. Nothing was
run. The versions are the ones locked in `uv.lock` where the library is
already a dev dependency. "FULL" means the candidate computes this
library's quantity under its definition, at the forms named. "PARTIAL"
says what is missing. "Differs" means the definitions do not match, so the
candidate cannot serve as an oracle. A "composite" splits the work: a
library computes the hard part (an EW mean, a density, a factorization),
and the test writes the rest by hand from the definition. The licence is
given so that a parked (licensed or BSL) library can be told apart from an
allowed one. Every candidate below is open source.
